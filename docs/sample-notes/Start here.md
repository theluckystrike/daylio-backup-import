# Daylio backup sample

This folder has a synthetic Daylio version 15 backup, `Demo backup.zip`, with two entries from 19 November 2023.

- Entry 15024: mood rad, activity long walk, text with bold HTML and one photo.
- Entry 15025: custom mood calm, activity reading, Unicode text.

Both entries have the same title and the same time. Run the command "Import a Daylio backup" and select the file to see the counts. The sample text and image are synthetic.
